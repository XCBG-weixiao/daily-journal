Mac 解锁、桌面可见后，界面工具仍报 ScreenCaptureKit `-3811`；重建工具会话后相同错误。此轮没有据此宣称新界面完整流程已通过。恢复桌面采集后按以下流程操作示例副本：

1. 新建活动 → 改名/颜色 → 新增指标 → 确认已使用指标不能移除。
2. 快速记录 → 展开正文 → 切换活动后再切回 → 验证输入 → 保存、搜索、阅读。
3. 正文输入、插入图片 → `⌘Z` / `⌘⇧Z` → 切换预览 → 保存核对正文。
4. 多选图片、拖入、粘贴 → 设置/取消封面 → 移除正文图片 → 清理未使用图片 → 从回收站恢复。
5. 归档活动 → 查看历史 → 取消归档；删除单条记录和含记录活动 → 预览 → 恢复。
6. 保留草稿 → 退出重开 → 继续编辑；外部修改同一记录 → 冲突比较 → 另存新记录。
7. 活动/标签/日期组合筛选、热力图指定日期新增、年份月份切换、较窄窗口阅读与返回。
8. 重启后恢复目录授权；权限失效显示错误，重新选择目录可读取原文件。
