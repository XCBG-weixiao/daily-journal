## 运行

应用已在 `127.0.0.1:3000` 启动。关闭进程后，在项目目录运行：

```sh
npm start
```

修改源码后重新执行 `npm run build`，或用 `npm run dev` 开发。安装到另一位置时先 `npm ci`，再 `npm run content:init`；需要演示数据时显式执行 `npm run seed:demo`。不要在已有个人数据的目录中填入演示数据。

内容位于项目根目录下的 `content/`，备份整个目录即可。`CONTENT_DIR` 可指向其他内容目录。浏览器实际读取的是运行服务的机器文件。
